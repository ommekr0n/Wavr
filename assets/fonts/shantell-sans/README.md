# Shantell Sans

By Shantell Martin, Arrow Type and Anya Danilova. Full, unmodified Google Fonts WOFF2 files for regular 400 and italic 700. Used as a Vietnamese-capable fallback when Comic Sans MS is unavailable; Japanese uses the existing Yomogi face restricted to Japanese Unicode ranges.

Project: https://github.com/arrowtype/shantell-sans

Language metadata: https://github.com/google/fonts/blob/main/ofl/shantellsans/METADATA.pb
