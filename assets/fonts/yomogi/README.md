# Yomogi

Handwriting font by Satsuyako, used by Nostalgia for Japanese text through a Unicode-restricted CSS face. Latin and Vietnamese retain the rounder reference typography.

- Project: https://github.com/satsuyako/YomogiFont
- Language metadata: https://github.com/google/fonts/blob/main/ofl/yomogi/METADATA.pb
- Unmodified full WOFF2, downloaded from Google Fonts:
  https://fonts.gstatic.com/s/yomogi/v13/VuJwdNrS2ZL7rpoPXQ.woff2
- License: [SIL Open Font License 1.1](OFL.txt).

A copy at `public/licenses/Yomogi-OFL.txt` accompanies the font in production builds.

The complete font is hosted with the app. CSS loads it when Japanese text needs it. Bold and italic are synthesized from the regular face to match the subtitle weight and slant. System Japanese fonts remain as fallbacks for characters outside Yomogi's coverage.
